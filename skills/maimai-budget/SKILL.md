# 麦麦预算配餐

本 Skill 依赖本地运行的麦麦预算配餐台服务。默认地址 `http://127.0.0.1:3210`；若不可达，先按用户提供的仓库位置启动 `npm start`。不要猜测安装目录、凭证路径或读取其他私人文件。所有调用使用 HTTP。

获取总预算（所有人合计，1–500 元）、人数（1–6 人）、主食偏好及是否配饮品。偏好取 `any/chicken/beef/fish`，默认 `any`；饮品默认配。说明每个人的搭配相同。缺少预算或人数时询问。

## 真实菜单

查询 `GET /api/status`。凭证未配置时说明配置步骤；只在用户同意演示时使用演示模式，不请求用户把 Token 发到聊天中。

如需新菜单，获取用户选择的城市和地标（不推断私人位置）：

1. `POST /api/live/stores`，JSON `{ "city": "用户指定城市", "keyword": "用户指定地标" }`。
2. 展示营业门店名称与地址，让用户选；只在用户授权你选择时自行选择。
3. `POST /api/live/menu`，JSON `{ "storeCode": "实际返回的编码" }`。
4. 使用返回的菜单与来源；如用户已要求配餐，可调用 `/api/live/activate`，传入返回的 `revision`。

## 计算

`POST /api/plan`，例如：

```json
{"mode":"live","budget":50,"people":1,"preference":"any","requireDrink":true}
```

仅在明确演示时用 `mode: "demo"`。显示返回的方案、餐品数量、合计、预算余量、理由、门店及读取时间。价格单位为整数分，展示时除以 100。

无解时使用服务返回的最低预算或缺失类别，不编造推荐。菜单过期、网络错误、未知 schema 时停止真实推荐，提示刷新或调整条件。不要声称“全菜单最低价”“官方已结算核价”或作营养、过敏安全保证。

说明方案仅为所筛选单品的参考合计，不含券、配送费、套餐优惠。本服务不提供下单或支付能力，凭证只留在本机。
